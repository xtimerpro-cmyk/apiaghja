⚙ SETUP JSONBIN (5 minutes)

JSONBin est un service de stockage JSON gratuit (10 000 requêtes/mois). Sans lui, les téléphones des clients qui scannent le QR ne peuvent rien enregistrer chez toi.

1. Va sur jsonbin.io et crée un compte gratuit (juste email + mdp).

2. Une fois connecté, clique « Create Bin » en haut à droite.

3. Dans le contenu, efface tout et remplace par juste :

[]

Donne-lui un nom genre « osteph-clients » et clique « Create ».

4. Copie le BIN ID (visible dans l'URL de la page après création, après /bin/ — c'est une longue chaîne de 24 caractères).

5. Va dans le menu « API Keys » à gauche → copie le X-MASTER-KEY (commence par $2a$10$...).

6. Reviens ici, clique « ⚙ Config JSONBin » en haut, colle le Bin ID + Master Key, puis « Tester ».

À partir de là, chaque client qui scanne le QR + tape ses infos est automatiquement ajouté à ton bin, et tu peux tout voir/gérer ici. ✦

⚠ Le Master Key est embarqué dans chaque QR (sinon le tel du client ne pourrait pas écrire). Quelqu'un de techniquement curieux pourrait l'extraire et écrire dans ton bin. Pour un food truck, le risque est faible. Si tu vois du spam, tu peux régénérer la clé sur jsonbin.io.
